# Student League Mobile

Flutter feature-based client for Android and iOS.

```
lib/
  core/       # networking, theme, routing
  features/   # auth, home, tournaments, matches, teams, players, statistics, profile, referee
  shared/     # shared widgets/models
```

Install Flutter SDK, then:

```bash
flutter pub get
flutter run
```

Referee mode screens use large action buttons for live event entry.
